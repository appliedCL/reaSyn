# Dataset and model card

reaSyn's local release contains references to existing human alpha-synuclein cryo-EM fibril coordinates, descriptive metadata and resampling draws. It is intended for reproducible structural-method development. It is unsuitable for clinical prediction, disease-mechanism inference or claims that absent fibril polymorphs have been recovered.

The acquisition snapshot has 225 entries. The existing inclusion review admits 170, leaves 53 pending and excludes two mouse-protein entries. Human protein expressed in animal models is separately annotated; it is not human patient material. Paper-derived metadata currently cover 13 entries across two studies and await human spot-check. Other fields retain unknown values or explicitly identified Atlas-derived provenance. Missing sample identifiers must not be treated as independent samples.

`structural_metadata.csv` preserves source identifiers, coordinate references, checksums, metadata values and provenance. `backbone_inventory.csv` identifies the chains and author residue numbers used. `similarity_matrix.csv` holds the upper triangular matrix, including self comparisons; the comparison is symmetric. `frozen_splits.csv` records conservative dependency components. `geometric_features.csv` contains seven descriptive features. `resampled_training_rows.csv` identifies every draw, its study, original coordinates, copy count, initial probability and conditional probability under the cap. No new coordinates are produced. Unknown original conformer population weights are handled by a declared uniform distribution within each study.

Coordinate data are available under [wwPDB CC0 terms](https://www.wwpdb.org/about/usage-policies). Attribution is retained through study DOIs and PDB accessions.
